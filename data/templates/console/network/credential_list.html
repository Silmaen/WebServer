Configuration OpenWrt

Pour permettre au monitoring d'interroger votre routeur OpenWrt, il faut :

  1. Installer les paquets : opkg install rpcd-mod-luci rpcd-mod-iwinfo
  2. Créer le fichier ACL /usr/share/rpcd/acl.d/netmonitor.json (accès lecture seule)
  3. Ajouter un utilisateur monitor dans /etc/config/rpcd
  4. Redémarrer rpcd : /etc/init.d/rpcd restart

L'utilisateur monitor n'a aucun accès shell ni droit d'écriture.
